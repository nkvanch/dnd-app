# Installing the Grimoire alpha (Android)

Grimoire is free and open source, works offline, and needs no account or external server. This is an alpha, so expect rough edges, and please tell me about them.

1. On your phone, open the download link and download Grimoire-alpha-0.1.0.apk (about 58 MB).
2. Open the downloaded file. Android will ask for permission to install apps from this source ("Install unknown apps"). Allow it for your browser or file manager only, and you can turn it off again afterward.
3. If Google Play Protect says the app is unrecognised, that is expected: this is a hobby alpha and it is not distributed through the Play Store. Choose "More details" and then "Install anyway" only if you are comfortable with that. The source code is public.
4. Open Grimoire. Everything stays on your device.

Optional sample packs: save the .grimoire-pack file to your phone, then open Grimoire, go to Homebrew, choose import, and pick the file. You will see a preview of what it contains before anything is added.

Verify the download (optional): the release lists a SHA-256. Compare it with Get-FileHash Grimoire-alpha-0.1.0.apk on Windows, or sha256sum Grimoire-alpha-0.1.0.apk on Linux or macOS.

Uninstall: remove it like any app. Your characters are deleted with it, so export a backup first if you want to keep them.

Supported today: Android only. There is no iOS build.

Feedback: https://github.com/nkvanch/Grimoire/issues
