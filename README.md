# Grimoire

A table companion app for 5th-edition-compatible tabletop roleplaying games —
character sheets, homebrew content authoring, and local LAN campaign sync
between a DM and players. Built with [Expo](https://expo.dev)/React Native.

Everything stays on your own devices. Nothing is collected or sent to any
server — campaign sync is direct device-to-device over your local network.

## Getting started

```bash
npm install
npx expo start
```

See [Expo's documentation](https://docs.expo.dev/) for running on a device,
simulator, or the web. A preview Android build is also published via
[GitHub Releases](../../releases) — see the latest release for a ready-to-install
`.apk`.
