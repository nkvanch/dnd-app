# Demo recording scripts

**Rule: original content only.** Every video uses the packs in `demo/` (all labelled "(Demo)"). Never load anyone else's homebrew on screen,
and don't open the official-content browser, the point is what the engine lets people *create*, not how much D&D content the app has.
Record on a fresh install with the alpha APK, screen-record at phone resolution, no voice-over needed (captions are fine), under 60 seconds.

Not recorded yet, this needs a phone. **Rehearse each flow once before recording**; I verified the pack contents in tests, not the tap-by-tap UI.

## A. The general 60-second demo (Zellorea, Jonoman, Nathan, Lee, Antonio), Aster Test Pack

| Time | On screen | Caption |
|---|---|---|
| 0–6 s | Grimoire home | "Your character shouldn't be limited by your character-sheet app." |
| 6–18 s | Homebrew → import `aster-test-pack.grimoire-pack` → the import preview listing 6 items, incl. the two pulled in as dependencies | "One file. It shows what it brings with it before it touches your library." |
| 18–30 s | Open the feat (or item) in its builder → **Test** button → before/after rows | "Test what it does before you save it." |
| 30–48 s | New character using *Aster-Touched (Demo)* → sheet: +1 CON, darkvision, the 2-use resource; equip *Aster Lantern* → +1 AC appears only after attuning | "Same systems as built-in content." |
| 48–60 s | End card: "Free · open source · works offline · no account or external server · Android" + the page URL | "Tell me where it breaks." |

## B. DM V, character-focused demo, Understudy Test Pack

Flow: `create unusual concept → custom subclass/feature → test effect → create character → resulting sheet`

| Time | On screen | Caption |
|---|---|---|
| 0–6 s | Grimoire home | "Can it represent the character you intended?" |
| 6–18 s | Import `understudy-test-pack.grimoire-pack`; open *The Understudy (Demo)* in the subclass builder | "An awkward concept: a limited pool of borrowed roles, a custom progression, a condition." |
| 18–28 s | Test button on the subclass → rows for the resource, +1 AC, the level-6 ability | "Test it first." |
| 28–50 s | Create a Bard, take the subclass at level 3 → sheet shows *Borrowed Roles* 3/long rest; jump to level 6 → *Cue the Spotlight* appears and applies *Spotlit* | "Then play it." |
| 50–60 s | End card | "Where does the app get in your way?" |
