# Future Content Browser

Deferred product requirement; do not partially implement during Device/UI Closure Pass 4.

The Compendium and Homebrew Library should be evaluated as one shared Content Browser shell with a library selector such as **Library: Compendium**. Candidate libraries are Available/Official, Homebrew, Favorites, and imported packs when supported. Search, filters, and sort should be shared. Content cards and active filter states need stronger visual distinction and contrast. All app filters require a dedicated UX redesign pass.
